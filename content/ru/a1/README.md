# Russian A1 content

This directory is the canonical home for new Russian A1 curriculum data.

## Canonical Stage 1
`stage_1_pareto.json` is the MVP Stage 1 source.

It contains:
- 65 reusable building blocks
- 35 conversational chunks
- ten 10-item micro-sessions
- mastery thresholds
- romanization fade rules
- the active-recall/recombination learning cycle

Principles:
- content is data, not hard-coded into UI components
- Cyrillic is visible from day one
- romanization is a temporary bridge
- prioritize high-utility vocabulary and reusable sentence patterns
- introduce small batches, then recombine them in listening/speaking tasks
- use active recall and spaced review rather than passive rereading

The older `curriculum/russian/` and `data/russian_stage_1.json` files are retained as source/reference material during migration and are not the canonical new curriculum.
